# Авторизація та особистий кабінет

Цей репозиторій розгортає статичний сайт із Vercel Serverless Functions, а не Next.js App Router. Сторінки `/login`, `/register` і `/account` налаштовані через Vercel rewrites; API використовує наявний Neon PostgreSQL.

## Налаштування

1. У Neon SQL Editor виконайте `database/schema.sql` у базі, яку використовує `DATABASE_URL`.
2. Додайте змінні середовища у Vercel (і локально для розробки):
   - `DATABASE_URL` — Neon connection string.
   - `SESSION_SECRET` — випадковий секрет щонайменше 32 байти. Наприклад: `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`.
   - `RESEND_API_KEY` — API-ключ Resend.
   - `EMAIL_FROM` — підтверджена Resend адреса відправника, наприклад `ВольтЗапас <noreply@example.com>`.
   - `ADMIN_PASSWORD` — пароль адміністратора для наявної панелі керування.
3. Переконайтеся, що Vercel використовує Node.js 22, і розгорніть сайт.

Реєстрація та відновлення пароля надсилають 6-значний код на 10 хвилин. Код обмежений п’ятьма спробами, повторне надсилання — раз на хвилину. Паролі зберігаються bcrypt-хешами; сесійний JWT зберігається у HttpOnly-cookie.

Замовлення, створені під час активної сесії, прив’язуються до користувача. Гостьові замовлення й надалі приймаються, але не відображаються в кабінеті. Доступ `GET /api/orders` для клієнта повертає лише його замовлення; адміністративний доступ зберігається через `x-admin-password`.
